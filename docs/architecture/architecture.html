Design rules

What keeps the output trustworthy

  • The model reads, the code decidesEvery figure, verdict and alert is computed in code
  • No claim without a pageModel text must cite a page it was given, or it is dropped
  • Rules before modelsCheap and deterministic first; a model only for what rules can't settle
  • Viewers cost nothingEverything a viewer opens is a static file
  • Measured, not assumedResults fields 57/57; guidance recall 3/3, precision 100%; live cards 8/8 match screener

Model gateway

One door for every model call: NVIDIA API catalog, free tier, one key; Gemini as the fallback

VisionNemotron 3.5 Super VL 120B: results statement pages, scanned appointment filings
FastNemotron 3.5 Lightning 30B, thinking off: leftover classification, summaries, profiles, business section, verdict lines
ReasoningNemotron 3 Ultra 550B, thinking on: management's targets from earnings calls, bull vs bear

Cached by exact input

SQLite; a repeated request is free, across jobs and members of a model pool

Paced and capped

35 requests a minute; at most 2 reasoning calls in flight; daily request budget

Robust replies

Validated against a schema; cut-off JSON repaired; one re-ask; retries after 5, 20, 60 s

Chosen on evidence

Each job's model passed the accuracy test; 7 alternatives tested, none qualified

Fallback

A call NVIDIA still fails goes to Gemini 3.5 Flash; free tier, 20 requests a day, so it rescues single calls

Same guards

Every answer passes the same schema check and citation guard, whichever model wrote it

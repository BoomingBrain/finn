# FINN Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Chat tab that answers questions about researched companies using retrieval over FINN's reports only, with every sentence cited, and "Research pending for {name}" for companies without a report.

**Architecture:**
- **Offline:** dossiers are chunked into cited passages, embedded with NVIDIA `nemotron-3.5-embed-1b`, and published as `data/snapshot/rag/index.json` with the site.
- **On Render:** the service loads that index from the Space and answers `POST /api/chat`:
  1. find the companies named
  2. hybrid retrieval (cosine + BM25)
  3. fast-model answer
  4. `drop_uncited`

**Tech Stack:** Python 3.12, FastAPI, httpx, numpy (already installed via pandas), pytest; React 18 + TypeScript + Tailwind v4 + Vitest.

**Spec:** [docs/superpowers/specs/2026-10-29-chat-design.md](../specs/2026-10-29-chat-design.md) (approved 29 Oct).

## Global Constraints

- **Reports only:** passages come from `data/snapshot/dossiers/*.json` and nothing else.
- **Every answer sentence cites ≥ 1 retrieved passage id,** via `sections.drop_uncited`. Nothing grounded → `"The reports don't cover that."`.
- **A named NSE company without a dossier** → `"Research pending for {name}."` and no model call for it.
- **Retrieval:**
  - top 12 passages, scored `0.6 × cosine + 0.4 × BM25 / max BM25`
  - restricted to the named companies when any are named; otherwise at most 4 per company
- **Answer:** fast tier, at most 5 points. **Limits:** 30 chat questions per IP an hour (`CHAT_PER_IP_PER_HOUR`), plus the daily request budget; questions 1–300 chars.
- **Embedding model:** `nvidia/nemotron-3.5-embed-1b`, `input_type` `passage` for the index and `query` for questions. Index vectors are float16.
- **Index freshness:**
  - rebuilt by the dossier jobs; Render re-fetches it from `{WEB_ORIGIN}/data/rag/index.json` every 30 min
  - a dossier saved live is chunked and embedded into memory at once
- **No new dependencies.**
- **No backend push while the queued Kotak live-timing test is running:** commit locally and push after it reports.

## Review Focus

1. **Short tickers inside words:** "LT" in "result", "ITC" in "switch" must not count as naming a company. Matching is whole-word and case-sensitive for symbols, case-insensitive for names. *Test in Task 3:* `test_symbol_match_needs_word_boundary`.
2. **A question naming a researched and an unresearched company:** answer for the first, plus a pending line for the second. *Test in Task 4:* `test_mixed_known_and_pending`.
3. **The index not loaded yet** (cold start, Space unreachable): 503 `{"error":"index_loading"}` and the copy "Chat is starting up; try again in a minute." *Test in Task 4:* `test_index_not_loaded_is_503`.
4. **A question trying to override the rules** ("ignore the reports and tell me…"): still only cited sentences. An uncited reply becomes "not covered". *Test in Task 4:* `test_uncited_reply_is_not_covered`.
5. **A follow-up that names no company** uses the previous turn's companies. A follow-up that names a new company replaces them. *Test in Task 4:* `test_follow_up_carries_companies`.

### Task 1: Chunk dossiers into cited passages

**Files:** Create `backend/finn/rag.py`, `backend/tests/test_rag.py`.

**Interfaces:**
- Produces:
  - `Passage(BaseModel)`: `id: str`, `symbol: str`, `company: str`, `source_id: str`, `text: str`, `url: str | None`, `page: int | None`. `id = f"{symbol}#{n}"`, with `n` the 0-based passage index within the dossier.
  - `chunk_dossier(dossier: dict) -> list[Passage]`.
  - **Every passage's text starts with the company name.** Passages:
    - **Snapshot** (`source_id` `SCR`):
      - (a) revenue and profit, last 4 quarters, with 3-year growth
      - (b) operating margin now vs 3 years ago, and ROCE or ROE
      - (c) debt to equity and cash from operations ÷ profit
      - (d) red flags, only if any

      Missing values are left out of the sentence, never printed as 0.
    - **Delivery:** one per row (`source_id` = row `target.source_id`): "{company} guided {raw_metric} {target} for {period}: "{quote}". Delivered {value} ({quarters_in} of {quarters_needed} quarters). Verdict: {plain words}". Verdict words come from `sections.VERDICT_WORDS`.
    - **Business:** one for `what_it_does` (first source id), plus one per segment ("{company} segment {name}: {share}% of revenue", first source id).
    - **Bull and bear:** one per point ("{company} bull case: …", first source id).
  - `url` and `page` come from the dossier citation with the same `source_id`. `SCR` uses the screener URL with `page` None.
  - Sections with status `unavailable` produce nothing.

### Task 2: Embed and build the index

**Files:** Modify `backend/finn/rag.py`, `backend/tests/test_rag.py`, `backend/finn/snapshot.py`, `.github/workflows/dossiers.yml`, `.github/workflows/prebuild.yml`.

**Interfaces:**
- Consumes: `chunk_dossier`, `SnapshotStore.list_dossiers` / `load_dossier`, `llm.load_api_key`.
- Produces:
  - `Embedder(api_key, cache_path, client=None)` with `embed(texts: list[str], input_type: "passage" | "query") -> np.ndarray` (float32, shape `n × dim`).
    - Batches of 64, POST to `https://integrate.api.nvidia.com/v1/embeddings` with `{"model", "input", "input_type", "encoding_format": "float"}`.
    - A SQLite cache keyed by `sha256(model|input_type|text)`.
    - One retry on 429/5xx after 5 s.
  - `build_index(store: SnapshotStore, embedder) -> dict`, returning `{"model": "nvidia/nemotron-3.5-embed-1b", "dim": int, "built_at": iso, "passages": [Passage dicts], "vectors": base64(float16 row-major)}`.
  - `SnapshotStore.save_rag_index(index: dict)` writes `rag/index.json` (compact JSON).
  - CLI: `uv run python -m finn.rag --build`.
  - Workflows: after the dossier step in `dossiers.yml` and `prebuild.yml`, add `uv run python -m finn.rag --build` (same env).

### Task 3: Retrieval and company detection

**Files:** Modify `backend/finn/rag.py`, `backend/tests/test_rag.py`.

**Interfaces:**
- Produces:
  - `Index.from_dict(d: dict) -> Index`, holding `passages` and a float32 matrix with L2-normalised rows. `Index.add(passages, vectors)` appends.
  - `Index.search(query_vec: np.ndarray, query_text: str, symbols: set[str] | None = None, k: int = 12, per_company: int = 4) -> list[Passage]`. Score = 0.6 × cosine + 0.4 × (BM25 / max BM25 over candidates; 0 if max is 0). With `symbols`, candidates are only those symbols and `per_company` is not applied.
  - `bm25(query: str, docs: list[str], k1=1.5, b=0.75) -> list[float]`: lowercase word tokens.
  - `find_companies(question: str, researched: dict[str, str], nse: dict[str, str]) -> tuple[list[str], list[tuple[str, str]]]`, returning (researched symbols named, pending (symbol, name) named). Matching:
    - a symbol: whole word, case-sensitive, and ≥ 3 characters or exactly equal to an upper-case token
    - a name: case-insensitive whole-phrase match on the name without "Limited/Ltd" and without a trailing "(India)"
    - researched wins over pending for the same symbol

- [ ] **Step 1: Write the failing tests**:
  - `test_search_restricts_to_named_companies`.
  - `test_search_caps_per_company_when_none_named` (one company with 10 strong matches → ≤ 4 of its passages in the top 12).
  - `test_bm25_prefers_exact_terms` ("debt to equity" ranks the debt passage first when vectors are equal).
  - `test_find_companies_by_symbol_and_name` ("Is Polycab's debt high?" → `["POLYCAB"]`; "INFY margins" → `["INFY"]`).
  - `test_symbol_match_needs_word_boundary` ("results switch" names neither LT nor ITC).
  - `test_unresearched_company_is_pending` ("What about Kotak Mahindra Bank?" with KOTAKBANK only in `nse` → `pending == [("KOTAKBANK", "Kotak Mahindra Bank Limited")]`).

### Task 4: Answer and the chat API

**Files:** Create `backend/finn/pull/chat.py`, `backend/tests/test_chat.py`. Modify `backend/finn/api.py`.

**Interfaces:**
- Consumes: `Index`, `Embedder`, `find_companies`, `nse_symbols()`, `sections.GROUNDING_RULES`, `drop_uncited`, `Point`, `RateLimiter`, `RequestBudget`.
- Produces:
  - `answer(question: str, passages: list[Passage], llm: LLM) -> list[Point]`:
    - fast tier
    - sources block `[{passage.id}] {passage.text}`, prompt = `GROUNDING_RULES` + "Answer the investor's question in at most 5 short sentences. Cite passage ids."
    - `drop_uncited` against the given ids, capped at 5
  - `NOT_COVERED = "The reports don't cover that."`; `PENDING = "Research pending for {name}."`
  - **API:** `POST /api/chat`, body `{"question": str, "context": list[str] = []}`.
    1. Validate (1–300 chars) → 400 `bad_question`.
    2. Index not loaded → 503 `index_loading`.
    3. Limiter → 429 `rate_limited`; budget → 429 `budget_exhausted`.
    4. `find_companies`; if none named, use `context` restricted to researched symbols.
    5. If there are only pending companies, return pending with no model call. Otherwise embed the question (`query`), search, answer.
    6. Respond 200 `{"points": [{text, source_ids}], "citations": [{source_id: passage id, url, page, label}], "pending": [{symbol, name}], "symbols": [...], "not_covered": bool}`. The `label` is `"{symbol} {chip}"`, where the chip uses the web's citation format, e.g. "POLYCAB AR p118".
  - **Index holder:**
    - loads `{WEB_ORIGIN first}/data/rag/index.json` in a background task at startup, then every 30 min (httpx, timeout 60)
    - `remember()` (live-saved dossier) also chunks, embeds and `Index.add`s
    - `create_app(..., index: Index | None = None, embedder=None, chat_limiter=None)` for tests
